# MCP-TodoAgent-Java
软件工程小组作业：基于Java实现MCP待办智能体
## 项目介绍
实现一个支持工具调用的大模型智能体，可以对话完成待办事项：添加待办、查看全部待办、删除待办。
纯Java实现，不使用Maven，JDK17。
## 功能列表
1. add：新增待办事项
2. list：列出所有待办
3. delete：删除指定待办
## 运行环境
- JDK 17
- IDEA
- VM参数：`-Dsun.stdout.encoding=UTF-8 -Dsun.stderr.encoding=UTF-8 --enable-native-access=ALL-UNNAMED`
## 使用说明
1. 将API Key填入代码对应位置
2. 配置好上面的VM选项运行主类
3. 在控制台输入指令和智能体对话
